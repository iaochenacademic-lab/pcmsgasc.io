## 建議實作順序

1. 視覺改版（配色、標題、英文小標、側欄分組、首頁橫幅、手機排行榜、B4、A6）：只動前端。
2. 簽到簡化（S1–S4、S7）：移除 QR，改為每課一組整窗有效的數字碼；先寫測試。
3. 批量登記（A1、A2）：新增批量 API，先寫測試。
4. 課次管理（A3、A4、A5）：總表、提醒、提前關閉簽到。
5. 請假與隱私（S5、S6）：學生申請＋管理員核准、管理員直接建立；待定標籤僅本人與管理員可見。先寫測試。
6. 規則設定（B1、B5）：D1 migration 加入每期分值與末 N 人設定，先寫測試。
7. CSV 匯出（A7）。

每批完成後依 AGENTS.md 依序跑 test、typecheck、lint、build、worker:check，並更新 PROJECT_STATUS.md。
