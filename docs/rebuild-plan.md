# pcmsgasc.io 重建計畫（已確認）

本文件記錄 2026-10-12 使用者批准的規格。新指示優先於舊原型說明。2026-10-29 起的調整（例如簽到改為整堂有效數字碼、批量登記、提前結束簽到）見 [設計與功能評估](DESIGN_REVIEW.md)。

## 目標與交付

為不足 100 人的國際議題研習學會重建繁體中文、手機及電腦適用的管理網站。設計採米白、深藍、少量金色，結合學術刊物式標題、留白與清楚的操作卡片及表格。OpenDesign 使用 Local Codex 建立全新設計專案。Cloudflare 只使用免費方案，首版部署於 workers.dev。GitHub 保留舊版本歷史與 AGPL 授權，使用重建分支與 PR。

技術：React、TypeScript、Vite、Workers API、D1。使用 SQLite Durable Objects 執行 bcrypt cost 12 及帳號登入並發控制，避免一般免費 Worker 的 CPU 限制。

## 帳號與隱私

- 成員表已核對 68 位學生、1 個 admin，無重複學號及缺少必要欄位。
- 學號登入，無公開註冊。學生各自生成隨機密碼，首次登入強制改密；admin 保留來源表現有密碼。
- 初始帳號表私人交付，不提交任何真實成員資料、密碼、密碼雜湊或密鑰至 GitHub。
- 重複匯入不覆寫已存在帳號的密碼。連續 10 次錯誤鎖定 5 分鐘。
- jose 與 Secure/HttpOnly/SameSite=Lax Cookie；30 天滑動閒置期限。重設密碼或停用後撤銷現有登入。
- 每個 API 在伺服器驗證身份、角色和帳號有效性；学生首次改密前不可使用其他功能。
- 社內實名排行榜可見姓名、班別與分數；請假類別與備註僅本人及管理員可見。

## 頁面

學生：首頁、簽到、活動詳情、個人活動與積分明細、排行榜、帳號設定、開發致謝。

管理員：成員新增與編輯、密碼重設、停用與恢復、課次與點名、活動與參與登記、分數修正、門檻設定、結算與封存、操作紀錄及資料匯出。

## 課堂與活動

- 所有時間為東八區。週五 12:55 起遲到，管理員可更改；預設簽到窗口 12:45–13:10。
- 管理員開啟才可簽到；未開啟或取消的課次不扣缺席。
- QR 碼與數字碼每 30 秒更新，登入後提交，伺服器驗證窗口、課次與有效碼。重複提交不重複計分。
- 管理員確認缺席、請假、補登後結課發布分數及排行快照。請假只有管理員登記流程。
- 出席 +0.5，遲到 -1，缺席 -2，公假/病假/事假 0；每課出勤狀態互斥。
- 課堂分享 +2，預設每人每課一次，可與出勤分相加。
- 講座/參觀/觀賽每次 +0.5；比賽由管理員設定分數，可記錄每人成績。
- 活動不設站內報名；管理員發布詳情並登記參與。撤銷或更正會修正分數並留下原因及操作者。
- 使用百分之一分的整數儲存分數，避免浮點誤差。

## 排行與週期

- 僅在籍學生參與當期排名，admin 不參與；不追扣加入前的課次。
- 紅線預設為倒數第二人的分數，該分數及以下全部待定，同分不拆開；管理員可切換手動分數門檻。
- 黃線初始未設定，管理員設定後，達到分數標示明年免面試達標。
- 尚無有效計分記錄時不顯示末位警示。紅黃線重疊時提示修正並暫停資格結算。
- 每課保存順位、分數、門檻及末位群組快照；同分顯示群組標識。
- 管理員設定截止時間；按截止時間形成待審快照，管理員逐一決定淘汰。停用保留歷史，不自動連鎖淘汰下一批。
- 重設即封存舊週期、建立由零開始的新週期；舊出勤、活動、排行及決定可查閱。

## 技術介面與驗證

同源 /api，依認證、本人資料、課次、活動、排行與管理操作分組。D1 保存成員、登入狀態、週期、出勤、參與、積分來源、快照及審計紀錄。設計生成只使用虛構資料。

必要驗證：首次改密、admin 密碼、登入競態和鎖定、角色越權、停用與撤銷；12:55 邊界、過期碼與重複簽到；取消課次與補登；出席加分享 2.5、遲到加分享 1；撤銷活動無殘留分；同分、門檻、截止、結算、快照、新期歸零；接近 100 人集中登入與簽到；型別、測試、建置、手機使用與公開資源敏感資料掃描。

正式資料在測試通過後才匯入，使用獨立測試環境。交付正式網址、私人帳號表、管理說明、資料匯出與回退方法。不可自動升級付費服務。
