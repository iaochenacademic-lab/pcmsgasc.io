# 管理、部署與回退

正式名稱：國際議題研習學會。現行規格見 [重建計畫](rebuild-plan.md)，實際驗收見 [重建進度](REBUILD_PROGRESS.md)。

## 管理員日常流程

1. 建立課次並確認日期、窗口與遲到時間；預設 12:45–13:10，12:55 起遲到，均為東八區。
2. 上課時手動開啟簽到，投放每 30 秒更新的 QR／六位數碼。學生登入後確認提交。
3. 核對出席、遲到、請假與分享；請假只由管理員登記。未開啟或取消的課次不扣缺席。
4. 結課後發布積分與順位快照。更正必須填理由；出席＋分享為 2.5 分，遲到＋分享為 1 分。
5. 發布活動詳情；參與與比賽成績由管理員登記，沒有站內報名。撤銷登記會同時修正積分。
6. 設定門檻和截止時間。紅線預設倒數第二位分數及以下全部待定；同分不拆開。黃線可保持未設定。
7. 截止後建立待審快照，逐一決定保留或淘汰；停用保留歷史，不連鎖淘汰其他人。
8. 校對後匯出備份、封存週期並建立新週期。新期從零計分，舊期唯讀。

## 帳號與私人交付

新增及重設密碼只顯示一次性初始密碼。請立即透過私人途徑交付本人；不要貼到公開聊天、GitHub、議題或提交。學生首次登入必須改密。停用、角色變更、改密與重設會撤銷既有登入。

本機私人匯入工具由 `scripts/import-accounts.ts` 提供，透過明確的 `--remote` 參數寫入指定 D1。正式匯入前先閱讀 [帳號 API](auth-api.md)，使用獨立測試環境。來源表需包含學生識別、姓名、班別與角色；admin 的來源密碼經私人輸入保留，學生密碼由工具逐人生成。重複學號不覆寫既有密碼。工具強制來源及交付檔位於倉庫外；Windows 上應先限制該私人資料夾的存取權限，不能上傳。

工具透過 `CLOUDFLARE_API_TOKEN` 環境變數取得有限 D1 權限，參數只接受非秘密的帳戶與資料庫識別。交付日誌在寫入資料庫之前落盤，未知結果以 `--recover` 核對；只交付狀態確認為 `created` 的帳號，不能重新生成密碼來猜測結果。

此版本不含真實帳號或初始管理員密碼。未完成正式匯入時登入不可用，不可為了演示添加公開後門。

## Cloudflare 免費部署

1. 確認授權的 Cloudflare 帳戶為 Workers Free，不能自行升級。
2. 建立獨立測試 D1 與正式 D1；將核對過的 database_id 填入各自設定。不要讓測試環境連接正式資料。
3. 先在本機依次通過 `npm test`、`npm run typecheck`、`npm run lint`、`npm run build`、`npm run worker:check`。
4. 確認目標後在測試資料庫執行 migration，部署測試 Worker，完成實際 Cookie、Session、角色及 100 人並發驗證，再安排正式部署。
5. 使用 `wrangler secret put SESSION_SECRET` 及 `wrangler secret put CHECKIN_SECRET` 的私人輸入，各自使用安全隨機秘密；不得放入命令參數、wrangler.jsonc、前端或 Git。
6. 使用 Wrangler 部署到 workers.dev，記錄版本 ID 與網址。正式上線前完成登入、改密、QR、匯出與手機驗收。

目前設定不啟用包含請求細節的遠端日誌；保留操作審計但不記錄密碼或 Session。免費配額不足時應失敗並告知管理員，不自動購買服務。[Cloudflare 免費方案文件](https://developers.cloudflare.com/durable-objects/platform/pricing/) 說明 SQLite Durable Objects 的免費可用性及超额失敗行為。

## 匯出及備份

管理員資料匯出包含社團資料、私人請假備註與歷史紀錄，不含認證秘密。請保存在受限私人位置。D1 全庫備份可能含密碼雜湊與 Session，亦屬高度私密資料，不提交至 Git。定期使用 Cloudflare 官方 D1 備份／Time Travel 功能，操作前核對帳戶與資料庫。

## 回退

- 程式回退：使用 Cloudflare 的版本與 rollback，先核對要回退的版本及其相容資料結構。不要單純回退程式而忽略已完成的 migrations。
- 資料回退：先停止寫入並取得當前私人備份，再依經驗證的 D1 復原程序還原；避免把學生的最新紀錄覆蓋掉。
- 舊原型：Git commit `24a9095` 保留原 Next.js/Supabase 程式。它使用不同資料庫，不能直接套用目前 D1 資料，也不應直接取代現行正式服務。

停止部署、恢復資料或重新匯入前，必須核對進度文件記錄的實際環境。未記錄遠端成功，不代表已經部署。
