## 已实现内容

### 认证与账号

- 预置用户名账号登录、登出、老师和成员角色分流；网站不开放注册，使用自定义 `public.users`，不使用 Supabase Auth 邮箱登录。
- bcrypt cost 12、连续 10 次登录失败锁定 5 分钟、首次登录强制改密；未知或停用账号执行固定 cost-12 虚拟比较，锁定账号保留原有直接返回行为。
- 成功登录通过原子 RPC 清零失败次数，若比较密码期间发生锁定，不签发 Session。
- `jose` 加密 Cookie，`Secure`、`HttpOnly`、`SameSite=Lax`，30 天滑动空闲期限；服务端每次查询用户，检查启用状态及 Session 版本，以数据库中的身份和角色为准。
- 改密原子递增 Session 版本，当前浏览器取得新版本，其他设备旧 Session 失效；管理员重置与停用也撤销旧 Session。
- `/auth/expired` 清 Cookie 后 302 到 `/login?reason=expired`，登录页显示中文失效提示。
- 改密接口实施 JSON 与同源检查，失败响应按约定续期，失效身份返回 401 并清 Cookie；明确挑选密码字段，客户端不能覆盖服务端身份。
- `scripts/create-user.ts` 支持单账号、CSV、重置、停用、启用、dry-run。CSV 全量格式、重复与库内存在性检查通过后，才执行单次原子批量插入。
- 各账号独立生成随机初始密码，仅在写库成功后一次性输出；失败不输出密码，不保存密码日志或文件。

### 签到、请假与界面

- 新增 `meetings`、`attendance_records`、`leave_requests`、`checkin_code_failures` 四张表，以及创建/管理场次、老师登记、成员签到、提交/审批/撤回请假的受限 RPC。
- 领域层包括时区转换、输入校验、随机签到码、状态优先级、有效名单、出勤率、老师与成员数据聚合。
- 老师可创建或按规则编辑、取消场次，重置签到码并清零错误次数，审批请假，登记出勤或恢复自动状态。
- 成员可输入签到码、提交事假/病假/公假、撤回自己的待审批申请，查看个人场次、记录、统计与审批意见。
- 七组业务写 API 使用统一同源/JSON/数据库身份/角色守卫；错误返回中文提示与对应状态码，全部响应 `no-store`。RPC 判定在途请求 Session 失效时返回 401 并清 Cookie。
- `/teacher` 提供正在签到的场次、待审批请假、新建场次及列表；`/teacher/meetings/[id]` 提供详情、统计、名单、编辑和审批/登记。
- `/teacher/meetings/[id]/display` 为无导航投屏页，每 10 秒刷新；仅签到开放时显示超大签到码，其余阶段显示明确状态。
- `/member` 提供 6 格签到输入、未来 14 天场次、请假表单、个人出勤及请假记录。
- 统一 AppShell、带文字的状态色、空状态、加载状态及错误重试；提交中禁用按钮，成功后刷新，字段错误就地展示。旧 EmptyDashboard 已移除。
- 成员场次查询明确排除签到码；repository、领域层与 API 均采用安全字段投影，成员记录及请假同时按用户筛选。

## 决策记录

| 主题 | 当前决定 |
|---|---|
| Session 撤销 | 用户保存正整数 `session_version` 与 `is_active`，载荷含版本；服务端每次按主键查用户，角色、姓名及强制改密以数据库为准。 |
| 改密 | 原子递增版本并给当前浏览器签发新 Session；RPC 额外比较预期版本，阻止已撤销的在途请求覆盖新密码。 |
| 失效路由与 Proxy | `/auth/expired` 清 Cookie 后 302 到失效登录页；Proxy 只解密、续期及基础分流。已登录访问登录页先到根页，再由数据库守卫分流，避免旧 Cookie 值造成循环。 |
| 改密失败续期 | 所有可续期的非 401 改密响应重设 Cookie；同源 403 仅续可解密 Cookie，不查库、不授权、不执行业务。无法解密配置时 500/no-store，不签发 Cookie。 |
| API 边界 | 新写接口与改密要求 JSON，Origin 必须存在且等于请求 origin；显式挑选 body 字段，身份及 URL ID 不接受客户端覆盖。 |
| 数据访问 | 全部经服务端 Admin Client；新表开 RLS 并限制权限；并发写入经 service_role 专用 RPC，SECURITY INVOKER、空 search_path。 |
| 并发与时间 | 同场次写入先取得共同 meeting 行锁，再处理用户及子表；锁后复核状态并读取实际时钟，避免排队期间越过时间边界。用户共享锁与改密/停用更新锁配合。 |
| 时区 | `CLUB_TIME_ZONE` 默认 `Asia/Shanghai`，数据库使用 timestamptz，服务端 Intl 转换及展示；非法时区报错，DST 不存在或重复的本地时间明确拒绝。 |
| 签到 | 服务端生成每场 6 位数字码；窗口为开始前 15 分钟至结束前，结束时即关闭；超过开始加阈值才迟到，默认 10 分钟。每人每场最多错 5 次，重置码清零错误次数。 |
| 请假 | 按场次申请事假/病假/公假，结束前可提交，开始后标补交；只可撤回自己的待审批申请；驳回必须有意见。 |
| 状态与恢复自动 | 签到或老师登记优先于批准请假，再按是否结束计算未签到/缺勤；缺勤不自动入库。恢复自动删除登记，不恢复此前覆盖的 self 签到。 |
| 名单与统计 | 当前启用且创建时间早于场次结束的成员进入名单；停用不计名单及统计，历史保留。出勤率为（已到＋迟到）/（已结束场次数－请假），取消场次不计，分母 0 显示「—」。 |
| 读取与泄漏保护 | 分页读取避免行数上限静默截断；成员查询显式列选择，repository/领域层/API 多处投影，禁止返回签到码及其他用户记录。 |
| 老师权限 | 所有老师权限相同。 |
| 设计与工具回退 | Ponytail 用于最小实现和审计开发工作流。OpenDesign 不可用，依计划简报直接实现白卡片、indigo 主色及带文字状态标签，没有 OpenDesign 稿件链接。Computer Use 浏览器运行时失败不计为 UI QA 通过。 |
| 依赖与范围 | 不新增运行时依赖，校验手写、时区用 Intl。暂不做活动报名、评分排行榜、CSV 导出、实时推送、通知、网页成员管理或 Vercel 部署。 |
