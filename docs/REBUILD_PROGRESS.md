## 審查與修正

獨立審查三項問題均已修正並複核關閉：

1. 結課先於取消提交時，不再讓失敗的取消請求撤回分數。條件更新與後續副作用同交易，權限失效會全部回滾。
2. 課堂／封存快照使用交易內當下分數來源，包含先提交的交錯寫入；只有資格結算按歷史截止時間還原。
3. 介面不以即時排行榜狀態錯誤禁止歷史截止結算，交由伺服器依截止資料判定。

瀏覽器另發現取消活動顯示多餘0；已統一出勤／參與 API 的布林欄位，新增真假值契約回歸並在最終瀏覽器畫面複驗修正。
