# 品牌規格｜國際議題研習學會

以米白紙感、深海軍藍與克制霧金，建立兼具學術刊物氣質與內部管理效率的視覺系統。

## 核心令牌

```css
:root {
  --bg: oklch(0.9615 0.0098 87.5);      /* #f5f2eb */
  --surface: oklch(1 0 89.9);           /* #ffffff */
  --fg: oklch(0.2890 0.0556 253.7);     /* #162c46 */
  --muted: oklch(0.5462 0.0039 145.5);  /* #6f716f */
  --border: oklch(0.8678 0.0159 86.4);  /* #d8d3c8 */
  --accent: oklch(0.6996 0.0824 86.2);  /* #b59b61 */
}
```

## 字體

- Display：`"Noto Serif TC", "Source Han Serif TC", "Songti TC", PMingLiU, serif`
- Body：`"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`
- Mono：`"IBM Plex Mono", "SFMono-Regular", Consolas, monospace`

## 視覺語言

1. 大型繁體中文襯線標題搭配小寫英文字眉，形成學術刊物式閱讀節奏。
2. 以細分隔線、充足留白和低圓角組件維持正式、可長時間使用的內部工具感。
3. 霧金只出現在品牌細節、關鍵門檻與少量高優先標記，不作大面積裝飾。
4. 自繪線條地球與經緯線作識別；不使用照片、漸層或無意義插圖。
5. 操作頁採清楚表格、狀態標籤與單一主要動作，所有狀態配對高對比前景／背景。
