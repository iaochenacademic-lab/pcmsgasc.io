# 國際議題研習學會｜產品設計規範

## 1. 產品定位

本原型是學會內部管理產品，不是行銷頁。學生端強調清楚掌握「今天要做什麼、目前紀錄如何」；管理員端強調可追溯、低失誤的名冊、點名、積分與學期治理流程。

- 入口：`index.html`
- 實作：原生 HTML、CSS、JavaScript，無後端與遠端相依
- 資料：頁面內建的虛構展示資料，不讀取其他目錄、真實成員檔、`.env` 或憑證
- 角色：頂部／側欄可切換學生與管理員視角

## 2. 視覺原則

1. **學術刊物的閱讀感**：大型繁中襯線標題、小寫英文字眉、細分隔線與充足留白。
2. **管理工具的效率**：高密度資訊使用清楚表格、狀態標籤、工具列和即時回饋。
3. **霧金只作標記**：只用於品牌細節、選取導覽與門檻參考，避免大面積裝飾。
4. **無泛用 SaaS 光澤**：不使用漸層、玻璃卡片堆疊、裝飾性 3D 或空洞大圖。
5. **資料邊界透明**：全站常駐「展示資料」提示，涉及匯出與操作時再次明示無真實後端。

## 3. 色彩

品牌原始色：米白 `#f5f2eb`、深海軍藍 `#162c46`、霧金 `#b59b61`。正式 CSS 以 OKLch 表示，方便建立一致的衍生色與狀態色。

| Token | OKLch | 用途 |
|---|---|---|
| `--bg` | `oklch(0.9615 0.0098 87.5)` | 全站紙感背景 |
| `--surface` | `oklch(1 0 89.9)` | 卡片、輸入框、浮層 |
| `--fg` | `oklch(0.2890 0.0556 253.7)` | 主要文字、主按鈕、圖表 |
| `--muted` | `oklch(0.5462 0.0039 145.5)` | 次要文字、說明 |
| `--border` | `oklch(0.8678 0.0159 86.4)` | 分隔線、控制項邊框 |
| `--accent` | `oklch(0.6996 0.0824 86.2)` | 品牌細節、焦點環、門檻標記 |
| `--success` | `oklch(0.43 0.11 157)` | 成功、出席、已發布 |
| `--warning` | `oklch(0.55 0.13 76)` | 待審、免面試黃線 |
| `--danger` | `oklch(0.52 0.17 26)` | 錯誤、淘汰紅線、破壞性操作 |

所有互動狀態必須成對調整前景與背景。主要按鈕 hover 仍保持白字／深色背景；所有可聚焦元素使用 3px 霧金 `:focus-visible` 外框。

## 4. 字體

```css
--display: "Noto Serif TC", "Source Han Serif TC", "Songti TC", PMingLiU, serif;
--body: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
--mono: "IBM Plex Mono", "SFMono-Regular", Consolas, monospace;
```

- Display：頁面標題、卡片主標、數字指標；利用襯線建立刊物感。
- Body：表格、說明、表單與操作；優先可讀性與系統可用性。
- Mono：英文字眉、編號、時間、代碼；呈現檔案與紀錄感。
- 桌面頁面標題：`clamp(38px, 5vw, 70px)`。
- 手機頁面標題：`clamp(35px, 11vw, 50px)`。
- 內文基準：16px／1.6；表格與操作字 13px；輔助字不低於 10px。

## 5. 間距與版面

基礎節奏以 4px 倍數建立，常用值為 8、12、16、20、24、32、44、64、76px。

- 桌面側欄：280px；小型桌面降至 244px。
- 頂欄：72px；手機為 64px。
- 主要內容最大寬：1440px。
- 卡片內距：24px；手機為 20px。
- 卡片間距：18–20px。
- 圓角：控制項 8px、卡片 14px、浮層 16px；不用膠囊卡片。
- 大型內容採 2 欄或 3 欄；1120px 以下逐步收斂；760px 以下全部改為單欄。

### 響應式導覽

- **桌面**：固定側欄包含品牌、角色切換、完整頁面列表與資料聲明。
- **手機**：固定底部顯示前四個主要頁面，第五格「更多」開啟完整頁面清單和角色切換。
- 表格在手機保留欄位語意，置於自身橫向捲動容器，不讓整個頁面橫向捲動。

## 6. 核心組件

### Brand Mark

自繪線條地球 SVG，由圓形、橢圓經線、水平緯線與中軸組成。線寬 1.2–1.35，永遠繼承當前文字色，不使用圖片資產。

### Page Header

包含小寫英文字眉、襯線主標、簡短說明與頁次。管理頁若有主要動作，只顯示一個實心主要按鈕。

### Card

- 紙面卡：白色與背景混合，1px 邊框，極輕陰影。
- 深色主題卡：海軍藍底、白字，用於首頁主視覺與重要識別。
- 卡片不使用彩色左邊框；狀態透過內容、標籤和完整背景配對呈現。

### Metric

由 12px 標籤、44px 襯線數字和 12px 補充說明構成。數字不得以裝飾取代語意。

### Button

- 高度至少 44px。
- 同一操作群組只有一個實心主要按鈕。
- 次要按鈕為描邊；低優先操作為無框文字按鈕。
- 危險操作使用紅色描邊，確認時才轉為紅色實心。

### Status Tag

使用低彩度實心底與高對比文字；success、warning、danger、outline 四種。標籤文字必須可單獨表達狀態，不能只靠顏色。

### Table

表頭 11px、內容 13px；每列 13–15px 垂直內距。操作集中於最右欄。排行榜同分群組使用霧金上線；紅、黃門檻使用對應色下線與文字標籤。

### Notice

一般、成功、警告、錯誤四種。錯誤訊息清楚說明「發生什麼」與「如何修正」，例如簽到碼不正確時提示確認最新 6 位數碼。

### Modal / Mobile Sheet

桌面置中，手機一般表單保留 12px 邊距；完整導覽使用貼底 sheet。`Escape` 關閉，開啟後焦點移至第一個可操作元素。

### Empty State

採文字與簡單符號，不用插畫。成員搜尋無結果時說明如何調整條件，並明示不會改動名冊。無有效積分紀錄在排行榜為中性狀態，不使用警告色。

## 7. 主要流程

### 學生

1. 學號＋密碼登入，無註冊入口。
2. 首次登入強制設定至少 10 碼、含英文與數字的新密碼。
3. 首頁優先顯示今日課堂、當期分數／排名／出勤、最近積分和即將活動。
4. 簽到接受 6 位數碼；有效展示碼為 `482731`，並提供成功、未開啟與錯誤狀態。
5. 活動頁只看已發布內容；不提供學生申請、站內報名或請假流程。
6. 個人紀錄才顯示自己的請假類別與備註。

### 管理員

1. 從總覽進入今日點名，開啟後取得輪替 QR 與 6 位數碼。
2. 在同一點名冊修正出席、遲到、缺席、公假、病假、事假與分享。
3. 結課發布後學生端才視為正式紀錄。
4. 活動由管理員發布並登記參與；比賽支援逐人成績，撤銷必填理由。
5. 分數修正採差額紀錄，不覆寫原始來源。
6. 截止快照保留門檻設定與同分群組，管理員逐一決定保留或淘汰。
7. 封存完成後新期只歸零本期分數，保留成員與歷史。

## 8. 計分規則

| 紀錄 | 分數 |
|---|---:|
| 出席 | +0.5 |
| 遲到 | −1 |
| 缺席 | −2 |
| 公假／病假／事假 | 0 |
| 分享 | +2，與出勤相加，每人每課一次 |
| 講座／參觀／觀賽 | +0.5 |
| 比賽 | 由管理員逐人指定 |

## 9. React + Vite 整合建議

建議以路由和領域拆分，不要直接把原型的 template string 搬進 React。

```text
src/
  app/
    router.tsx
    AppShell.tsx
  features/
    auth/
    attendance/
    activities/
    members/
    scoring/
    thresholds/
    archives/
    audit/
  components/
    PageHeader.tsx
    MetricCard.tsx
    StatusTag.tsx
    DataTable.tsx
    Notice.tsx
    ConfirmDialog.tsx
  styles/
    tokens.css
    globals.css
```

- 將 `styles.css` 的 `:root` 令牌原樣移入 `tokens.css`。
- 角色、目前學期、成員權限由正式 API 回傳，不以前端切換取代授權檢查。
- 點名 QR／數字碼應由伺服器產生並設短效期限；前端只顯示剩餘時間。
- 分數與狀態更新使用 append-only 事件紀錄，避免覆寫造成稽核斷點。
- 請假類別與備註須在 API 層實作本人／管理員欄位權限，不只在介面隱藏。
- 所有危險操作採二次確認並回傳操作紀錄 ID。

## 10. 無障礙與驗收

- 所有控制項可用鍵盤操作；焦點狀態清楚可見。
- 表單 label 與輸入欄一一對應；錯誤欄使用文字說明。
- 正文對比至少 4.5:1，大字與圖示至少 3:1。
- 互動目標至少 44×44px。
- 尊重 `prefers-reduced-motion`。
- 320px 寬度不得出現頁面級水平捲動；資料表可在自身容器內捲動。
- 無有效紀錄、尚未開啟、搜尋無結果與資料錯誤都必須有清楚且非責備式的空／錯誤狀態。
